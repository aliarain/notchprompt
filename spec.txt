Extra Features (P0.5: New, High-Impact, Quick Builds)
These are "launch differentiators"—add wow factor without bloating. Scoped minimally: Use existing Apple MLKit/Shortcuts for AI; simple OAuth for integration; in-app referral UI.

Basic AI Script Generator
Description: On-device AI (using Apple's Create ML or Hugging Face transformers via Core ML) to generate/enhance scripts from prompts. E.g., input "Sales pitch for SaaS tool" → outputs structured script (Intro/Key Points/CTA). Limit to 500 words; no fine-tuning.
Why Extra? Builds on script editor; virality via "AI-powered" marketing. Effort: Low—integrate pre-trained model, UI prompt field.
User Story: As Alex, I input a topic and get a starter script to tweak.
Edge Cases: Handle empty prompts; fallback to templates.
Dev Estimate: 1 day (AI squad). Success: 40% users try it in beta.

HubSpot CRM Integration (Basic)
Description: One-click auth to pull deal notes/scripts from HubSpot into app. Auto-load for calendar-linked calls (via Apple Calendar API). No write-back; read-only. Premium gated.
Why Extra? Targets sales users; quick win with OAuth2. Effort: Medium—API calls local, no backend.
User Story: As Alex, I connect HubSpot and scripts auto-populate for my next demo.
Edge Cases: Revoke access; offline fallback.
Dev Estimate: 1.5 days (Integrations squad). Success: 20% beta users connect.

Built-in Referral System
Description: In-app "Share with a friend" button—generates unique referral link (via Firebase Dynamic Links or simple UUID). Referrer gets 1-month premium free on signup. Tracks via local analytics (no server).
Why Extra? Drives Day 1 growth; zero-cost virality. Effort: Low—UI + email/share sheet.
User Story: As Alex, I refer colleagues and unlock premium.
Edge Cases: Duplicate referrals; privacy opt-out.
Dev Estimate: 0.5 days (UI squad). Success: 15% referral conversion.
