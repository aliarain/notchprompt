# Contributing to NotchPrompt 🎙️

We love your input! Whether it's a bug report, a feature request, or a code contribution, we welcome all help to make NotchPrompt better for everyone.

## How Can I Contribute?

### Reporting Bugs
- Search existing issues to see if the bug has already been reported.
- If not, open a new issue with a clear title and description.
- Include steps to reproduce the bug and details about your macOS version.

### Suggesting Enhancements
- Open a new issue with the "enhancement" tag.
- Describe the feature you'd like to see and why it would be useful.

### Pull Requests
1. **Fork the repo** and create your branch from `main`.
2. **If you've added code**, please include comments or documentation where necessary.
3. **Draft a clear PR description** explaining what your changes do.
4. **Build and test** your changes locally before submitting.

## Development Setup

### Prerequisites
- macOS 14.0+
- Xcode 15.0+

### Step-by-Step
1. Clone your fork:
   ```bash
   git clone https://github.com/YOUR_USERNAME/NotchPrompt.git
   ```
2. Open the project in Xcode:
   ```bash
   open NotchPrompt/NotchPrompt.xcodeproj
   ```
3. Make your changes and build (`Cmd + B`) to verify.

## Code of Conduct
Please be respectful and professional in all communications. We aim to foster a welcoming and inclusive community.
